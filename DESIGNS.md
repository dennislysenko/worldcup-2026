# Redesign shortlist

Five whole-site design directions, tiered by build confidence. Each = full site
in a new visual language (header → hero E → follow teams → upcoming bangers → calendar).

## Tier 1 — Easy (one-shot, high level)
- [x] **Stadium Night** — dark, neon pitch lines, glowing scores, electric green/magenta. → `design-stadium-night.html`
- [x] **Almanac / Newsprint** — broadsheet sports page, serif, columns, box scores. → `design-almanac.html`

## Tier 2 — Medium (a few iterations)
- [x] **Sticker Album** (built → `design-sticker-album.html`) — Panini foil stickers, glossy shine, retro grid.

## Tier 3 — Reach (needs design language + components + back-and-forth)
- [x] **Editorial Bold** (built, type-driven → `design-editorial.html`) — magazine cover, oversized headlines, full-bleed photography.
- [x] **Chalkboard Tactics** (built → `design-chalkboard.html`) — coach's chalkboard, hand-drawn arrows, chalk texture.
